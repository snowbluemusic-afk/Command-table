# The Mending Hour (Android)
Cozy, offline Android repair-and-story game. First playable chapter with radio, watch, lamp, handheld console and music box repairs.
This branch is isolated from the main work-mode-nfc project and exists solely to generate the Mending Hour APK.
Run the GitHub Actions workflow "The Mending Hour - Android APK"; download "The-Mending-Hour-v0.1.0-APK" from the completed run, unzip and install app-debug.apk.
