# The Mending Hour — Enchanted Workshop v0.4
Offline Android prototype using an embedded WebView.
- Original illustrated fantasy shop environment and eight character portraits, stored locally for offline play.
- 12 authored repair jobs and continued repair orders after chapter completion.
- 8 puzzle families: rune alignment, wire sorting/connecting, gear fitting, music-box melody, automaton reassembly, pressure valves, solder traces, lens polish/calibration.
- Repair pipeline: inspect clues, diagnose, use object-specific fasteners, open, repair, put casing back, refasten, function test, choose price.
- Customer relationships, keepsakes, reports of stolen goods, shop decorations, coin and word-of-mouth progression.
- Portrait mobile-first UI. Basic sound, no timers and offline saving. Android application ID preserved across v0.1–v0.4.
- Assets are original for this prototype. Third-party free asset candidates are documented in the design review but **not bundled**; adding them requires a consistent art direction and license check.
Build via the GitHub Actions workflow in this branch, download the APK artifact and install app-debug.apk.
