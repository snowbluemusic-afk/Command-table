# Public-build verification

This branch validates that GitHub Actions executes in the standalone public Command Table repository.

## Build acceptance

- [ ] Recovery preflight and Commander import tests pass.
- [ ] Pinned Forge builds with Command Table Java adapter.
- [ ] Bundled, offline card scripts are included in the APK.
- [ ] Android APK passes signature and integrity checks.
- [ ] Emulator installation and startup reach the Command Table WebView.
- [ ] Actual 1v1, three-player and four-player Commander gameplay is verified separately.

**An APK compile or a home-screen screenshot does not prove a playable Commander game.**
